## Brand Idea

Edura is not just a jobs board. The visual language should feel like a smart matching system for education: warm, optimistic, precise, and slightly playful.

Core sentence:

> לא מחפשים משרה. עושים מאץ׳.

The brand personality is built around the Edura smile/wink mark. It should recur as a functional motif: status, match progress, badges, empty states, celebrations, and friendly system feedback.

## Colors

Use a tight palette:

- Night blue: `#0F1B2D`
- Magenta: `#E6007E`
- Light gray: `#F3F5F8`
- White: `#FFFFFF`

Magenta is the main action/accent color. Night blue is for structure, text, and premium/important surfaces. Light gray is for calm backgrounds and inactive states.

Avoid introducing extra dominant colors unless they serve data/status meaning.

## Shapes And Components

Use:

- 8px radius for cards, buttons, chips, inputs, and panels.
- Thin borders in light gray.
- White cards on white/light-gray surfaces.
- Magenta dots as recurring brand markers.
- Night-blue panels for “smart match” moments.
- Speech bubbles and stickers sparingly for friendly guidance.

Avoid:

- Decorative grid backgrounds.
- Large abstract blobs.
- Heavy gradients.
- Tall, crowded cards with too much text.
- Generic emoji.

## Icons

Icon style:

- Thin line icons.
- Night-blue stroke.
- Small magenta accent or dot.
- Simple, rounded, readable at small sizes.

Main icon concepts from the board:

- Jobs: briefcase with smile.
- Search: magnifier with smile.
- Profile: user with smile.
- Chat: bubble with magenta dots.
- Saved: heart with magenta smile.
- Notifications: bell with magenta dot.
- Filters: sliders with magenta accent.
- Education: graduation cap with magenta tassel.
- Match: puzzle / smile / check.
- Future: flag/star with magenta motion.

Use these directions when creating or adapting icons instead of mixing unrelated icon styles.

## Matching Flow

The match explanation should move right-to-left in Hebrew.

Recommended sequence:

1. נקודה
2. מחפשים / תחילת קשר
3. אדורה מאתרת
4. יש מאץ׳
5. החיוך חוזר
6. חיוך נרגש
7. אדורה :)

For homepage explanation:

1. מספרים מה מחפשים
2. אדורה מחברת נתונים
3. מקבלים התאמות

Important: use the provided match-step assets as the visual source of truth for the smile states. Do not redraw the Edura smile from scratch in CSS unless the final result visually matches the reference assets.

Arrows must point from right to left on desktop. On mobile, the flow can stack vertically.

## Writing Tone

Short, clear, friendly Hebrew.

Prefer:

- "לא מחפשים משרה. עושים מאץ׳."
- "ספרו לנו מה אתם מחפשים."
- "אדורה מחברת נתונים."
- "מקבלים התאמות רלוונטיות."

Avoid long explanatory paragraphs inside cards. Put detail after the user chooses a path.

## Homepage Direction

The first screen should include:

- Clean header: logo + hamburger.
- Main line: "לא מחפשים משרה. עושים מאץ׳."
- Short supporting copy for both teachers and managers/schools.
- A smart match card in night blue.
- Four primary paths:
  - לפרסם משרה
  - למצוא עבודה
  - מכרזי ניהול
  - למצוא מורים
- A right-to-left match flow using the Edura smile motif.

The experience should feel like Edura is guiding the user toward a match, not merely listing ads.
